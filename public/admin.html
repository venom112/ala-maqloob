لوحة تحكم ع المقلوب

الدخول بحساب Google للإيميل المسموح له بس.

لازم تظبط دخول Google الأول

  1. افتح Google Cloud Console ← Credentials واعمل OAuth client ID من نوع Web application.
  2. في Authorized JavaScript origins حط عنوان موقعك بالظبط (مثلًا ).
  3. انسخ الـ Client ID وحطه على السيرفر في متغير البيئة GOOGLE_CLIENT_ID وأعد تشغيل السيرفر.
